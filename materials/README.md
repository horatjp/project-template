# materials/ — ファイル原本のため方

受領・作成したファイル(PDF・スライド・Word 等)の原本を置く。

## ルール

- 命名は `YYYY-MM-DD-<topic>.<ext>`(受領日・作成日)
- 保存したら journal の当日エントリからリンクし、出所(誰から・どこから)を1行残す
- 原本に認証情報・第三者の個人情報が含まれる場合は、保存・変換の前にユーザーへ確認する
  (変換版では該当部分をマスクする)
- 1画面で見渡せなくなったら年別サブフォルダ化(AIが提案する)

## AI可読化: 同名 `.md` の併置

PDF・スライド・Word などAIが読みにくい形式は、**受領時に**同名の Markdown に変換して併置する
(「後で変換する」はしない):

```
materials/
├── 2026-07-26-proposal.pdf   # 原本(正)
└── 2026-07-26-proposal.md    # AI可読の変換版(派生)
```

- 変換 `.md` の冒頭に出所メモを書く: 原本ファイル名・出所・変換日・変換者(AI名)
- **原本が正**。変換では図表・レイアウト・注釈が失われうるため、内容の齟齬や重要な判断では
  原本を確認する。変換で拾いきれなかった図表があれば、その旨を `.md` に明記する
- AIは通常 `.md` を読み、原本は必要時のみ開く
- 画像(スクリーンショット等)はAIが直接読めるため変換不要
