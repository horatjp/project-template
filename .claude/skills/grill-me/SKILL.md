# grill-me — 計画のストレステスト

この計画のあらゆる側面について、共通理解に達するまで徹底的にインタビューする。
設計の決定木を枝ごとに下り、決定同士の依存関係を1つずつ解決していく。

- 質問は1回に1つだけ
- 各質問には、自分の推奨回答を添える
- コードベースを調べれば答えが出る質問は、聞かずに調べる
- 全枝を解決したら、合意事項の一覧と、計画に反映すべき修正点をまとめて提示する
