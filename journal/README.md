# journal/ — 時系列ログのため方

「何が起きたか」を時系列でためる場所。1日1ファイル `YYYY-MM-DD.md`、書式は `_template.md`。

## ルール

- **その場で書く**: 出来事・打ち合わせの直後に都度記録する(「後で書く」はしない)。
  セッションの区切りでAIが書くのが基本
- **追記専用**: 過去エントリは書き換えない(リンク補完・明白な誤字修正のみ可)
- **事実を書く**: ここに書くのは「起きたこと」。それ以外は振り分ける —
  - いま何が open か → `STATUS.md`(journal にも記録として残す)
  - 後の作業が前提にする判断 → `docs/decisions/` に決定記録を起こし、ここには1行+リンク
  - 受領・作成したファイル → `materials/` に保存し、ここからリンク+出所1行
  - 詳細は `AGENTS.md` の「記録の境界」

## ナレッジになる流れ

journal は生の記録で、セッション開始時に読まれるのは直近の1〜2件だけ。後の作業が前提にする判断や
事実は、後から昇格させるのではなく**その場で** `docs/decisions/` や `docs/` の生きた文書(要件・
関係者情報など)に書き、journal には「いつそうなったか」を残す。
