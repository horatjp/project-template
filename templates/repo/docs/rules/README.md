# docs/rules/ — パス限定の規約

特定のパス・ファイル種別を触るときだけ守る規約を、1関心事1ファイルで置く(learnings からの昇格先のひとつ)。
どの CLI でも読める普通のファイルなので、Claude Code 以外の AI にも効く。AGENTS.md の
「`docs/rules/` に、触るパスを対象とする規約があれば先に読む」が入口。

書き方(例: `db-migrations.md`)— 冒頭の「対象」行で、どのパスを触るときに読むかを示す:

```markdown
# DBマイグレーションの規約

対象: `db/migrations/**`

- 洗い替え処理は挿入・更新を先に、削除は最後に行う(途中で失敗しても行が消えない)
- 既存カラムの型変更は新カラム追加 → 移行 → 旧カラム削除の3段階で行う
```

- ここに置くのは「守らないと壊れる」規約のみ。網羅的な長文にしない。理由を1行添える
- 機械的に検証できるものは hooks のほうが確実
